# snowflake-community-resources

A collection of Snowflake resources, code, and learnings that I share with the community: practice material for certifications, SQL and Python snippets, small tools, and notes from real-world projects.

Most of what you find here is linked from posts on Reddit and other community channels. If you arrived via a link, the relevant folder is usually named in the post.

## What's inside

| Folder | Content |
|---|---|
| `snowpro-core-quiz/` | Self-contained HTML question catalog for SnowPro Core exam preparation. Open it in any browser, no setup required. |
| `sql/` | SQL snippets and examples for Snowflake (queries, governance, performance, and more). |
| `python/` | Python scripts and Snowpark examples. |
| `learnings/` | Short write-ups of things I learned along the way: pitfalls, patterns, and tips. |

Folders are added as the collection grows. Each folder has its own short README explaining what it contains and how to use it.

## Getting started

1. Clone the repository or download it as a ZIP:

   ```bash
   git clone https://github.com/<your-username>/snowflake-community-resources.git
   ```

2. Open the folder you are interested in and read its README.
3. For the HTML tools, simply open the `.html` file in your browser.

For SQL and Python files, adjust database, schema, and warehouse names to your own environment before running anything. Review code before executing it in a production account.
